# Pictos des quatre éléments

Un picto par profil, animé en CSS (`pictos.css`, coupé avec `prefers-reduced-motion`). Repris de vjuju/design@2df7fba.

| Fichier | Élément | Profil | Famille |
|---|---|---|---|
| `feu.svg` | feu | Financeur·se | chaud |
| `air.svg` | air | Éclaireur·se | froid |
| `eau.svg` | eau | Expert·e | chaud |
| `terre.svg` | terre | Porteur·se de projet | froid |

Usage : coller le `<svg>` en ligne (les animations visent ses classes internes), charger `pictos.css`. Taille 48 px (40 px sur mobile). Chaque SVG définit ses propres `id` (`g-feu`, `g-eau`, `goo`) : un seul exemplaire de chaque par page.
