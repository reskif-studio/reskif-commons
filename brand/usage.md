# Usage de la marque

## Logo
- Fichier de référence : `brand/logo/reskif_logo.svg` (identique à https://reskif.org/reskif_logo.svg).
- En navbar : hauteur **28 px** (`h-7 w-auto`), lien vers `/` ou https://reskif.org, `alt="Reskif"`.
- Toujours en SVG ; ne pas déformer, recolorer ni ajouter d'effet sur le logo.
- Sur fond foncé ou riso, prévoir assez de contraste ; en cas de doute, poser le logo sur une pastille blanche.

## Style graphique
- Bordures franches couleur **encre** (1 px), coins droits sur les étiquettes, boutons **pilule** (`rounded-full`) fond encre, texte blanc, hover `brand-blue-700`.
- Fonds « papier » clairs (bleu, jaune, rose) pour les sections calmes ; **sections riso** (image tramée bichrome + dégradé) pour les moments forts. Voir `brand/riso/`.
- Header : blanc translucide (`bg-white/90 backdrop-blur`), bordure basse encre.
