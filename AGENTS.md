# Règles communes des agents Jean-Claude (tous les projets)

1. Pour tout ce qui touche à l'identité Reskif (logo, couleurs, typo, composants, scène 3D, pictos, footer, ton), **consulte ce dépôt d'abord** : `git clone --depth 1 https://github.com/reskif-studio/reskif-commons.git` (ou `git pull` s'il existe déjà), puis lis `README.md`.
2. **Copie** les fichiers nécessaires dans le dépôt du projet (ex. `public/reskif_logo.svg`, `public/css/reskif.css`, `brand/pictos/*.svg`) et cite la version en commentaire : `reskif-commons@<commit court>`.
3. Respecte `brand/usage.md` (univers nuit, chaud/froid réservés aux rôles, logo non déformé) ; pour tout travail visuel, applique aussi la skill frontend-design d'Anthropic.
4. Ce dépôt est **en lecture seule** pour toi. Pour proposer une évolution des communs, demande-la à Julien ; ne tente pas d'y écrire.
5. Le contenu de ce dépôt complète tes règles de projet, il ne les remplace pas : ton périmètre reste ton projet.
